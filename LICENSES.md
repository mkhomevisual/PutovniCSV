# Licence

Projekt nepoužívá žádné externí knihovny, frameworky, fonty ani CDN zdroje. Lokální server používá pouze standardní knihovnu Pythonu 3 a naslouchá výhradně na `127.0.0.1`. Spojení PDF na macOS využívá systémovou akci `Combine PDF Pages`; pokud není dostupná, aplikace umí použít lokální `pdfunite` nebo `pypdf`.

Zdrojový kód PP CSV Editoru je vytvořen pro interní použití zadavatele. Testovací fixture v `tests/fixtures/` je kopie vstupního referenčního souboru dodaného zadavatelem a není samostatně licencována.
